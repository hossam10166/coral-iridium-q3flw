# BEST UNITED Accounting Application 📊

تطبيق محاسبي متكامل ومتطور لإدارة الحسابات والبيانات المالية بكفاءة وسلاسة.

An integrated and advanced accounting application designed to manage financial data and accounts efficiently and smoothly.

---

## 🚀 التقنيات المستخدمة / Technologies Used

* **Frontend:** TypeScript, HTML5, CSS3, Vite (للبناء والتشغيل السريع)
* **Backend & Database:** Firebase Firestore (قاعدة بيانات فورية وآمنة)
* **Environment Management:** Bun / npm (إدارة الحزم والاعتماديات)

---

## 🛠️ التثبيت والتشغيل المحلي / Installation & Local Setup

لصيانة وتطوير المشروع محلياً على جهازك، اتبع الخطوات التالية:

### 1. استنساخ المستودع / Clone the repository
```bash
git clone https://github.com
cd coral-iridium-q3flw
```

### 2. تثبيت الحزم / Install dependencies
إذا كنت تستخدم **Bun** (كما يظهر في ملف القفل الخاص بك):
```bash
bun install
```
أو باستخدام **npm**:
```bash
npm install
```

### 3. إعداد المتغيرات البيئية / Environment Variables
قم بإنشاء ملف باسم `.env` بناءً على النموذج الموجود في المشروع:
```bash
cp .env.example .env
```
*ملاحظة: تأكد من إضافة مفاتيح Firebase الخاصة بك داخل ملف `.env` الجديد.*

### 4. تشغيل المشروع / Run the development server
```bash
bun run dev
# أو
npm run dev
```

## 🔒 الحماية والأمان / Security & Rules

المشروع مجهز بقواعد حماية مسبقة لـ Firebase Firestore متواجدة في ملف `firestore.rules` لضمان حماية بياناتك المحاسبية وسجلاتها من الوصول غير المصرح به.
